## What it does

`main.ts` writes a single line — a museum placard for an ordinary office
object treated as an ancient artifact — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

The placard (166 characters, one line):

> Printer, c. 2007. Plastic, toner, spite. Ritual object of the open-plan tribe; fed paper and prayer daily, it answered only in error codes, and was worshipped anyway.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Requires Node 22 or later. The output file is written with mode `0644`.
